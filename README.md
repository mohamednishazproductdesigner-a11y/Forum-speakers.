# FORUM Speakers

Animated event speaker showcase with a white interface and browser-frame presentation.

## Preview
Open `index.html` in a browser. No installation or build is required.

## GitHub Pages
1. Upload `index.html` and this README to your repository root.
2. Open Settings → Pages.
3. Choose Deploy from a branch, select main and / (root), then Save.

The speaker names, event and generated portraits are fictional demo content.
